నమస్తే 🙏

Individual households తమ ఇంటి ఖర్చులు సులభంగా track చేసుకోవడానికి నేను **Budget Padmanabham** అనే simple app తయారు చేస్తున్నాను.

ప్రతి నెలా డబ్బు ఎక్కడికి వెళ్తుంది, ఏ category లో ఎక్కువ ఖర్చు అవుతోంది, savings ఎందుకు తగ్గుతున్నాయి అన్నది clear గా చూడటానికి ఇది ఉపయోగపడుతుంది.

**ఇది ఎలా ఉపయోగపడుతుంది?**

- మీ కుటుంబం ఖర్చులు ఒకే చోట track చేయవచ్చు
- Daily expenses వెంటనే add చేయవచ్చు
- Income, expenses, savings ఒకే dashboard లో కనిపిస్తాయి
- కిరాణా, school, fuel, medical లాంటి categories ద్వారా spending అర్థమవుతుంది
- మీ household members మాత్రమే invite code ద్వారా join అవ్వవచ్చు
- Charts మరియు insights తో spending pattern clear గా తెలుస్తుంది
- ఇది **completely free**. 

**Privacy గురించి:**

- మీ family details app లో save అయ్యే ముందు family privacy password తో lock/encrypt అవుతాయి
- అంటే password తెలియని వాళ్లకు ఆ details readable గా కనిపించవు
- Backend database లో కూడా expenses, income, categories, family/member names, budget plans, insights readable format లో ఉండవు
- Database admins కి కూడా family privacy password లేకుండా ఈ family details చదవడం సాధ్యం కాదు
- ఈ privacy password app database లో store చేయబడదు. అది మీ family దగ్గరే ఉండాలి
- Password పోతే locked/encrypted family data recover చేయడం సాధ్యం కాదు
- Login కోసం email/user id, invite status, timestamps లాంటి basic account metadata మాత్రం system లో ఉంటుంది
- App bank account, UPI PIN, card details, SMS, contacts, location అడగదు / read చేయదు

ప్రస్తుతం ఈ app **invite-only basis** లో ఉంది.

మీ కుటుంబానికి ఉపయోగపడుతుందని అనిపిస్తే, లేదా ఒకసారి try చేయాలని ఉంటే, మీ **email address** నాకు personal message చేయండి. నేను invite పంపిస్తాను.

అవసరం లేకపోతే ignore చేయొచ్చు 🙏
